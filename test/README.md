## 后续测试怎么归档

- 单个模块的测试放到 `test/<模块名>/`，例如后续可用 `fast_lio/`、`reve/`。跨模块联调放到 `test/integration/<链路名>/`。有测试后再创建目录。
- 每个目录用 `README.md` 说明测试目的、前置条件、启动命令、关键话题和通过标准。需要实机、仿真或 bag 回放时，写清楚输入来源。
- 启动文件和可复现的脚本放在对应模块下，文件名写明用途。运行日志、曲线截图和大体积 bag 放到 `logs/` 或数据目录，在测试说明里记录路径。
- 在每个测试 launch 文件顶部用 XML 注释写出可直接复制的启动命令。
